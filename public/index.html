📚 Developer API Resources & Quickstart
Download openapi.yaml Open Interactive API Docs ↗

Get your first AI-generated track in under five minutes. Use your generated API key (Live or Test) in the Authorization: Bearer <key> header.

1. Generate Music Track (cURL)
curl -X POST http://localhost:3000/v1/generations \
  -H "Authorization: Bearer sk_test_..." \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: job-$(date +%s)" \
  -d '{
    "prompt": "Lo-fi chill beats with mellow piano",
    "duration_sec": 30,
    "license": "royalty_free"
  }'
2. Poll Status & Fetch Audio URL
curl http://localhost:3000/v1/generations/gen_xyz123 \
  -H "Authorization: Bearer sk_test_..."

# Response when succeeded:
# {
#   "status": "succeeded",
#   "output": {
#     "audio_url": "http://localhost:3000/v1/audio/...",
#     "duration_sec": 30
#   }
# }
